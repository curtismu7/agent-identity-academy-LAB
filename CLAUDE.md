# agent-identity-academy

Demo-tier standalone lab: the Agent Identity Academy as a standalone — 13 lessons, one per agent type and per control (landscape, OIDC sign-in, delegated access, Personal Agent, Digital Assistant, MCP, Authorize, human approval, A2A, Privilege MCP, threat defense, lifecycle, evidence map), each with a frame-by-frame movie reel, a mock-claim evidence drawer with a claim diff, and a diagram-studio diagram. Five lifecycle stages (Discover, Register, Authenticate, Authorize, Govern) light up per lesson. Mock-only by design — no live mode.

- Run: `./scripts/run.sh` (http://127.0.0.1:7831). Test: `npm test` (server = `node --test test/*.test.js` — a **glob, never a directory**; web = vitest; packaging = `node --test scripts/*.test.mjs`). Build: `npm run build` (web first, `npm run build` runs it). Preflight: `npm run doctor`. Reset: `npm run reset`. Talk track: `npm run talk-track` (regenerates `docs/talk-track.md` from `server/src/story.js` — never edit that file by hand). Content pack: `npm run content-pack`. Diagrams: `node scripts/build-diagrams.mjs` (regenerates `server/diagrams/*.json` from the lessons — run after editing lessons, then `npm run content-pack && npm run talk-track`).
- Content lives in `server/src/story.js` (LESSONS with actors, frames, stages, products, presenter; STAGES; TALK_TRACK); diagrams are diagram-studio/1 documents in `server/diagrams/`, generated one per lesson plus the stage model; `doctor.js` fails on a lesson without a diagram, an unused diagram, a frame whose stage is not a real stage or not declared by its lesson, or a non-reserved host in the story.
- Rules that bite: **port 7831 only** (`server/src/safety.js` refuses any other; Docker publishes `127.0.0.1:7831:7831` only); **netguard** — zero real outbound calls, self-tested, asserted by a test; **mock-only** — no live mode exists, the lab contacts no tenant in any mode; `AIA_MODE_REAL=1` only enables the rule-19 Real switch and the page opens on a REAL modal that says the content is still the simulation. Loopback bind, Host check, same-origin writes, only `.invalid`/`.example` hosts.
- Rule-19 toggle shape: `POST /api/mode` takes exactly `{ source: "mock" | "real" }`; 409 + reason when Real is not enabled (`AIA_MODE_REAL` unset); `GET /api/info` returns `source` and `realAvailable`. `MODE=mock` in `.env` forces the start mode. Never remove or hide the toggle.
- Per-visitor workspaces (rule 13): `X-Workspace` header, default `default`; Reset restores that workspace only.
- Honesty rule: every token in a frame is labelled mock (`User access token (mock)` …) and the evidence drawer is headed `MOCK · sample claims`; the sample issuer is `auth.example-idp.invalid`. Do not present a sample claim as a real token.
- Tests: run with globs (`test/*.test.js`, `scripts/*.test.mjs`); the compose test pins the loopback-only publish, read-only FS, non-root, `restart: unless-stopped`, and the rule-19 env pass-through.
- No AI attribution anywhere: never a `Co-Authored-By` trailer or a "Generated with" line in commits, PRs or files.
